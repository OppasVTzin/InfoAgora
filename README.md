# InfoAgora

Aplicação mobile desenvolvida com FlutterFlow para consumo e gerenciamento de notícias em tempo real. O app oferece uma experiência moderna, intuitiva e responsiva, permitindo que usuários acompanhem conteúdos atualizados de forma rápida e eficiente.

## 🧠 Sobre o Projeto

O InfoAgora foi criado com o objetivo de centralizar notícias em uma única plataforma, com foco em usabilidade e performance.

A aplicação permite visualizar conteúdos informativos de forma organizada, com suporte a imagens, navegação entre telas e estrutura escalável.

Ideal para projetos de:

- Portais de notícias
- Apps informativos
- MVPs de conteúdo digital

## 🛠️ Tecnologias Utilizadas
- FlutterFlow
